# Docker

## What is Docker?

Docker is an open-source platform that helps developers package their applications and dependencies into isolated environments called containers.

## What is an Image?

An image is a read-only template or blueprint for creating containers.
It contains the application code, runtime, libraries, and system tools needed to run an application:

## What is a container?

A container is a lightweight, standalone, executable package of software that includes everything needed to run an application:

- The application code
- Runtime (like Node.js, Python, Java)
- System tools and libraries
- System settings

## What is Docker Compose?

Docker Compose is a tool for defining and running multi-container Docker applications.

## How do container health checks work?

A container health check used to determine the an application inside the container is healthy or not.

## How do you set container resource limits?

Container resource limits allow us to control how much CPU and memory a Docker container can use.

## How do you deploy multiple Node.js containers?

We can deploy multiple Node.js containers by creating multiple container instances from the same Docker image.
